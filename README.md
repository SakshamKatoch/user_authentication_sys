# User Authentication System
A web-based user authentication application developed using Python and Streamlit. The project provides a simple and secure way for users to create accounts, log in, and access a personalized dashboard. Link: https://userappenticationsys-ay44nqy53b5oshe6lz5gxc.streamlit.app/

# Features
* User registration and login
* Secure password hashing using bcrypt
* SQLite database for storing user information
* Session-based authentication
* Input validation
* Duplicate email prevention
* User dashboard
* Logout functionality
* Basic role support for users

# Technologies Used
* Python
* Streamlit
* SQLite
* bcrypt

# Security
Passwords are hashed using bcrypt before being stored in the database. The application does not store passwords as plain text.
